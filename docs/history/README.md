# Design history

These documents come from the original Agentic Engineering v5 toolkit (October 2026): its audits, redesign notes, implementation plan, release notes, and the original README. They are kept as a record of why the toolkit is shaped the way it is.

They describe the toolkit before it became the `ae` plugin, so some details are out of date: install steps that copy `.claude/` into each project, and the `triage` and `simplify` skills, which are now part of `/ae:ae` and `/ae:refactor`. The repository `README.md` and `docs/QUICKSTART.md` describe the current plugin.
